# Student Grade Calculator

## Description

Student Grade Calculator is an Android application that allows students to enter three grades and calculate their average and corresponding letter grade.

## Features

- Enter three grades
- Calculate the average grade
- Determine the letter grade
- Display the calculation result
- Simple and easy-to-use interface

## How It Works

The user enters three grades and presses the "Calculate Grade" button. The app calculates the average of the three grades and displays the average and corresponding letter grade.

## Grade Scale

- A: 90–100
- B: 80–89
- C: 70–79
- D: 60–69
- F: Below 60

## Technologies Used

- Kotlin
- Android Studio
- Android SDK
- XML
